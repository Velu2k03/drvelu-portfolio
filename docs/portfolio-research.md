# Portfolio research

Reviewed September 27, 2026, using 2025-2026 hiring and portfolio sources. These are qualitative signals, not a claim that all employers screen candidates in the same way.

## Sources and application

1. [Anthropic careers](https://www.anthropic.com/careers): emphasizes direct evidence such as independent work and open-source contributions, and welcomes varied educational backgrounds. Applied by moving four real repositories close to the hero and connecting the biology/teaching background to investigation and communication.
2. [Applied AI Engineer, Enterprise Tech](https://job-boards.greenhouse.io/anthropic/jobs/5057647008): includes LLM applications, evaluation, Python/TypeScript, MCP, and deployment. This is a senior role, used only for engineering signals, not to imply the candidate meets its experience requirement. Applied by making each project's scope and implementation stack explicit, including RAG, Docker/GCP, and Playwright where supported.
3. [June 2026 n8n AI Automation Developer hiring post](https://community.n8n.io/t/hiring-n8n-ai-automation-developer-remote/298577): requests workflow examples, API integrations, communication skills, a portfolio, contact details, and a Loom introduction. Applied with clear workflow positioning and prominent video, GitHub, and email links. This community listing is an example of screening requests, not an endorsement of the employer or compensation.

## Content decisions

- Use the exact AI Automation Engineer positioning, with n8n and LLM integrations first.
- Show four bounded projects, each with short copy, relevant tags, and a direct GitHub link.
- Remove placeholder projects, unrelated vendor links, unsupported counts and impact claims, and service-selling language.
- Distinguish independent project work from paid team experience.
- Keep contact and the current resume one click away. Use working email/phone links instead of a nonfunctional form.
- Use actual repository screenshots where available and thematic photography for other covers, with provenance recorded in image credits.
- Keep shared content in one module so secondary routes do not retain obsolete positioning.

No latency, accuracy, user count, cost reduction, or production usage claims were invented. Evaluation metrics and additional live demos can be added when there is supporting project evidence.
